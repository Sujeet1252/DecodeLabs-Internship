# 📊 Advanced EDA & Feature Engineering
### DecodeLabs Industrial Training Kit – Data Science Project 1

## 📌 Project Overview

The objective is to transform raw, messy data into a clean, machine learning-ready dataset using advanced Exploratory Data Analysis (EDA) and Feature Engineering techniques.

---

## 🎯 Objectives

- Clean and preprocess real-world data
- Handle missing values using statistical techniques
- Detect and treat outliers
- Perform Exploratory Data Analysis (EDA)
- Engineer meaningful features
- Prepare the dataset for Machine Learning

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Workflow

### 1️⃣ Data Loading

- Import dataset
- Inspect shape
- Check data types

### 2️⃣ Data Cleaning

- Handle missing values
- Remove duplicates
- Fix inconsistent data

### 3️⃣ Exploratory Data Analysis

- Statistical Summary
- Distribution Analysis
- Correlation Analysis
- Visualization

### 4️⃣ Outlier Detection

- Boxplots
- IQR Method
- Z-Score Method

### 5️⃣ Feature Engineering

- Create new features
- Transform variables
- Improve predictive power

### 6️⃣ Final Dataset

- Clean
- Balanced
- Ready for Machine Learning
